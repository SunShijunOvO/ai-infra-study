# 主题学习笔记

`notes/` 保存可复用的 AI Infra 知识，不保存项目当前状态或临时待办。新笔记采用小写连字符文件名，例如 `gpu-memory-hierarchy.md`。

## 写作要求

- 一个文件聚焦一个清晰问题或主题。
- 开头写一句“结论摘要”，让读者快速判断是否相关。
- 区分来源事实、自己的推导、实验观察和未验证假设。
- 优先链接仓库内实验；外部资料记录标题、URL 和访问日期。
- 有数值结论时记录硬件、软件版本、参数和复现命令。
- 内容过时后标记状态并链接替代笔记，不直接抹去有价值的历史。

## 笔记模板

```markdown
# 主题名称

- 状态：草稿 / 已验证 / 已过时
- 最后更新：YYYY-MM-DD
- 结论摘要：一到三句话。

## 问题

这篇笔记要回答什么？

## 核心概念

必要的定义、机制和推导。

## 实验或证据

环境、步骤、结果，以及仓库内产物链接。

## 权衡与适用边界

结论在什么条件下成立，何时不适用？

## 开放问题

- 尚未验证的问题。

## 资料

- 标题 — URL（访问日期：YYYY-MM-DD）
```
