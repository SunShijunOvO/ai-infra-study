# 项目目标与边界

## 愿景

通过可运行的实验、可复用的笔记和阶段性项目，建立对 AI Infrastructure 的系统理解，并能解释、设计、实现和评估典型 AI 系统的基础设施。

## 当前目标

项目仍处于初始化阶段。具体学习方向、技术栈、时间投入和成果形式尚未与用户确认；在确认前，不把任何细分路线视为既定范围。

## 建议覆盖面（待确认）

- 计算基础：GPU/加速器、互联、存储与性能模型。
- 分布式训练：并行策略、通信、容错、调度与检查点。
- 推理系统：模型服务、批处理、KV Cache、量化与延迟/吞吐优化。
- 数据与评测基础设施：数据流水线、实验追踪、可观测性和评测。
- 平台工程：容器、Kubernetes、资源编排、成本与可靠性。

以上只是用于规划讨论的候选地图，不代表当前承诺。

## 工作原则

1. 以动手实验验证概念，笔记应链接到可复现的证据。
2. 先建立性能与系统直觉，再堆叠框架使用技巧。
3. 明确区分已验证事实、个人理解、假设和开放问题。
4. 每个阶段产出可检查的成果，而不仅是“读过”。
5. 优先使用最小实验解释一个问题，再扩展到复杂系统。

## 成功标准（待细化）

- 能从计算、内存、通信和调度角度分析训练或推理瓶颈。
- 能构建至少一个可复现的分布式训练实验和一个推理服务实验。
- 能用数据比较方案，并解释关键权衡。
- 仓库中的笔记和实验足以让未来会话复现结论。
