# 项目记忆索引

这套文档把不同生命周期的信息分开保存，降低信息过期和重复维护的风险。

| 文件 | 回答的问题 | 更新频率 |
| --- | --- | --- |
| [PROJECT.md](PROJECT.md) | 为什么做、做什么、不做什么？ | 低 |
| [CURRENT.md](CURRENT.md) | 现在在哪里、接下来做什么、卡在哪里？ | 每次实质工作后检查 |
| [ROADMAP.md](ROADMAP.md) | 计划按什么阶段推进？ | 里程碑变化时 |
| [DECISIONS.md](DECISIONS.md) | 为什么选择当前方案？ | 关键决策产生时 |
| [SESSIONS.md](SESSIONS.md) | 上一次重要工作留下了什么上下文？ | 重要会话结束时 |
| [../notes/](../notes/README.md) | 某个 AI Infra 主题学到了什么？ | 形成可复用知识时 |

原则：`CURRENT.md` 是短期状态的唯一事实来源；其他文件不要再维护另一份“当前待办”。
