# 学习路线图

## 当前状态

路线规划已确定。学习按[CUDA 算子开发学习路线](cuda-learning-plan.md)的 L0—L7 知识依赖推进，项目以 `Transformer CUDA Kernels Lab` 贯穿，并按[项目成果路线](cuda-operator-roadmap.md)的 M0—M6 交付可验证版本。两条路线通过阶段出口衔接，均不设置时间表。

## 规划约束

- 成果驱动：每个具体知识点都应落到一个动手实验，并形成可检查的结果。
- 项目贯穿：用一个持续演进的项目承载实验、优化记录和最终简历成果。
- 无固定时间表：不规定日期、周数、每日时长或每周学习量，只描述依赖顺序、下一步和完成标准。
- 正常流推进：每次从当前状态选择一个最小但完整的成果，验证后再推进下一项。
- 按需补基础：围绕 CUDA 算子开发补 GPU、系统、C++、PyTorch 和性能分析知识，不先行通读所有前置课程。

## 成果里程碑

1. M0：可复现的 CUDA 项目骨架。
2. M1：GPU 编程模型与数据映射。
3. M2：并行归约原语。
4. M3：Transformer 基础算子。
5. M4：系统化性能工程与代表性算子深度优化。
6. M5：PyTorch 自定义算子接入。
7. M6：端到端演示、复现报告与求职表达。

每个里程碑的对应知识、实验、项目成果和完成标准见[详细路线](cuda-operator-roadmap.md)。

## 学习阶段

1. L0：开发闭环与最小系统基础，对应 M0。
2. L1：CUDA 执行模型，对应 M1.1—M1.2。
3. L2：CUDA 内存模型与数据布局，对应 M1.3。
4. L3：并行协作与归约，对应 M2。
5. L4：数值计算与 Transformer 基础算子，对应 M3。
6. L5：CUDA 性能工程，对应 M4。
7. L6：PyTorch 自定义算子工程，对应 M5。
8. L7：综合复盘与求职准备，对应 M6。

各阶段的必学内容、暂缓内容、掌握标准、补课触发规则和资料策略见[学习规划](cuda-learning-plan.md)。
