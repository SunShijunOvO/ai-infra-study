# 学习实验

`experiments/` 保存为理解具体知识点而设计的小型、可丢弃实验。实验回答一个问题，不承担贯穿项目的稳定接口。

## 组织方式

实验按学习阶段和项目里程碑分组，再按问题命名：

```text
experiments/
└── l0-m0/
    └── cuda-event-vs-cpu-timer/
        ├── README.md
        ├── src/
        └── results/
```

后续按实际进度创建 `l1-m1/`、`l2-m1/` 等目录，不预先生成空阶段。

## 每个实验至少记录

```markdown
# 实验名称

## 问题

## 事前预测

## 控制变量与环境

## 操作步骤

## 结果

## 解释

## 结论与限制

## 对项目的影响
```

## 边界

- 一次实验只改变一个主要变量，并保留可比较基线。
- 项目代码不得依赖 `experiments/`；验证有效的做法应整理后进入 `projects/transformer-cuda-kernels/`。
- 小型结果表、关键图表和摘要可以提交；构建产物、缓存和大型 Profiler 原始文件不提交。
- 实验失败也可以保留，只要失败原因、证据和结论值得复用。
