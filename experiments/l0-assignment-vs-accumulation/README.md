# 赋值与累加对初值的依赖

## 问题

输出数组的初值是否影响赋值与累加的结果？

## 事前预测

用户在对话中已指出 `+=` 依赖初值；首次检查时未在源文件中记录具体数值预测；后续已补充正确的输出注释，不将补记当作事前预测。

## 控制变量与环境

- 用户自行编写 [main.cpp](main.cpp)。A 为 1、2、3、4，B 为 10、20、30、40，C、D 初值均为 100。
- 主要变量：C 使用赋值，D 使用累加；输入与输出初值相同。
- Ubuntu 26.04.1，G++ 15.2.0，C++17；程序只在 CPU 上执行。

## 操作步骤

在仓库根目录执行以下命令，构建产物放入 Git 忽略的临时目录：

```bash
mkdir -p .tmp/l0-assignment-vs-accumulation
g++ -std=c++17 -Wall -Wextra -Wpedantic experiments/l0-assignment-vs-accumulation/main.cpp -o .tmp/l0-assignment-vs-accumulation/main
.tmp/l0-assignment-vs-accumulation/main
```

## 结果

2026-09-17，Codex 根据用户源码重新编译，无警告，编译和运行退出码均为 0。每行分别为 C[i]、D[i]：

```text
11, 111
22, 122
33, 133
44, 144
```

## 解释

赋值直接覆盖 C 原值；累加读取 D 原值再加上 A、B 之和，因此每个 D 比对应 C 大 100。

## 结论与限制

本例中覆盖写入不依赖输出旧值，累加依赖输出初值。全部数组已初始化且循环范围合法；没有使用未初始化读取来做实验。本实验没有验证 GPU 执行、显存分配或传输。
